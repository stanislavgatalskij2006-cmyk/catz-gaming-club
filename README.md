# C.A.T.Z. — сайт по макету Pixso

Готовый адаптивный сайт на HTML, CSS и JavaScript. Установка пакетов и сборка не нужны. Все изображения, шрифт и библиотеки находятся внутри проекта.

## Запуск

Из этой папки выполни:

```sh
npm start
```

Открой `http://127.0.0.1:4173`. Требуется Node.js 18 или новее. Альтернатива без Node.js:

```sh
python3 -m http.server 4173 --directory dist
```

Не открывай `index.html` через `file://`: браузер блокирует JavaScript-модули в этом режиме.

## Что работает

- Первую секунду после готовности изображения свет и техника выключены. Затем поэтапно включаются неон зала, дальний и передний мониторы, клавиатуры и мышки. Есть прогрев подсветки экранов и мягкие световые импульсы. Полный запуск длится 2,9 секунды после паузы. Кнопка «Свет и техника» внизу первого экрана переключает всю сцену.
- Навигация по секциям, мобильное меню, четыре категории ПК и три зоны PS5.
- Выбор зоны, даты, времени, длительности и количества мест или гостей.
- Расчёт PC: цена × часы × количество мест. Расчёт PS5: цена × часы за всю зону.
- Сохранение одного плана в `localStorage`, просмотр, редактирование и удаление.
- Выгрузка `.ics` для календаря с корректным часовым поясом и длительностью.
- Галерея с переключением изображений кнопками и клавишами, FAQ, управление с клавиатуры, закрытие окон Escape.
- Локальные Lenis, GSAP и один сдержанный фон Vanta. На телефонах — нативная прокрутка и статический фон. Учитывается `prefers-reduced-motion`.

## Редактирование

Тексты и тарифы находятся в `dist/index.html`. В каждой карточке атрибуты `data-id`, `data-name`, `data-price`, `data-type` и `data-max` используются калькулятором. При изменении тарифов обнови и видимую цену, и `data-price`, и соответствующий пункт `#plan-zone`. Задержка включения `1000` миллисекунд находится в функции `scheduleBoot` файла `dist/assets/hero-power.js`, последовательность — в массиве `STARTUP`. Подробности и тайминг описаны в `MOTION.md`.

## Публикация на своём хостинге

Загрузи **содержимое `dist/`** в корень сайта. Подойдёт обычный статический хостинг, Nginx, Netlify, Cloudflare Pages или GitHub Pages. Сервер и база данных для текущих функций не нужны. Относительные пути поддерживают размещение в подпапке.

## Границы текущей версии

Заявки никуда не отправляются. План визита не резервирует место, наличие мест не проверяется, платежи не принимаются. Контакты клуба в макете не предоставлены и не выдуманы. Изображения являются концепт-визуализациями, что обозначено на сайте. Цены взяты из макета и показаны как ориентировочные «от».

## Проверка

`npm run check` проверяет синтаксис JavaScript. В браузере проверены тарифы PC/PS5, сохранение после перезагрузки, календарь, запрет времени в прошлом, галерея, FAQ, меню и ширины 320, 390, 768, 991, 1280 и 1440 px. В режиме таймеров проверено: сцена выключена на 999 мс, запуск начинается на 1000 мс. В отдельном тесте контроллера прошли 9 проверок: полный запуск, отмена, быстрые переключения, reduced motion, скрытая вкладка, bfcache и очистка ресурсов. Библиотеки и изображения не требуют внешних CDN.
